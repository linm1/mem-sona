# mem-sona Setup Instructions

## Prerequisites
- Node.js 18+ installed
- npm or yarn
- Convex account (sign up at https://convex.dev)

## Initial Setup

### 1. Install Dependencies
```bash
npm install
```

### 2. Configure Convex (Interactive)
You need to run this command in an interactive terminal:
```bash
npx convex dev
```

This will:
- Prompt you to log in to Convex (or create an account)
- Create a new project or link to an existing one
- Generate the `convex/_generated` directory with API types
- Start the development server

### 3. Set Environment Variables
Create a `.env.local` file in the Convex dashboard or use `npx convex env set`:
```bash
npx convex env set GEMINI_API_KEY your_gemini_api_key_here
npx convex env set VOYAGE_API_KEY your_voyage_api_key_here
```

### 4. Deploy Schema
Once `npx convex dev` is running, it will automatically deploy the schema from `convex/schema.ts`.

### 5. Verify Deployment
Check the Convex dashboard to see:
- All 5 tables created: resources, items, categories, graphNodes, graphEdges
- Indexes created for each table
- Vector indexes for items and graphNodes (1536 dimensions)

## Development Workflow
```bash
# Start Convex dev server (watches for changes)
npm run dev

# Deploy to production
npm run deploy
```
